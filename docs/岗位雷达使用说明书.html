01这是什么，不是什么

先说清楚边界，后面就不会有落差。

它做的事

  • 抓：你正常在 BOSS 搜岗位，它在旁边把列表里的岗位（含薪资、区域、福利、标签、公司阶段）收下来，存到你本机。
  • 排：按你设的薪资底线、想去的区、双休、加分/踩雷词、HR 活跃度、公司阶段打一个 0–100 的分，分数高的在上。
  • 筛：明显不合适的（外包、驻场、单休、薪资不达标）自动标成「已排除」，不占你的注意力。
  • 投：勾上想投的岗位，它按你设的间隔一个个打开详情页、点「立即沟通」、补发你为这个岗位写的那句话术。
  • 记：投过哪家、什么时候、成功没成功，都记下来，同一条岗位不会重复投。

它不做的事（重要）

  • 不替你注册、不碰你的账号密码，也不会代发简历。用的是你自己已经登录的浏览器。
  • 不是大模型。分数是本地规则算出来的，话术是模板 + 你的简历原句拼出来的——所以它「快且免费」，但话术需要你看一眼再发（后面第三节教怎么写）。
  • 不能改 BOSS 的站内默认招呼语。点「立即沟通」时，BOSS 一定会先发出它自己存的那句，扩展只能在后面补第二条。这是平台规则，绕不过去（见 07）。
  • 不上传任何数据。唯一的外部请求是你自己填了「高德 Key」时算通勤距离用的。
适合谁：正在海投、每天要翻几十上百个岗位、懒得一个个看 JD 的人。不适合：只想投 3–5 家精品岗位的人——手动投反而更好，因为你本来就会认真看每一份 JD。

02安装（3 步，2 分钟）

还没上架应用商店，用「加载解压缩的扩展」方式安装。装一次就好，之后自动生效。

解压安装包 把收到的 jobradar-v0.8.6.zip 解压到一个固定的文件夹（例如 D:\JobRadar）。装好后别再移动或删除这个文件夹，否则扩展会失效。
打开扩展管理页，开启「开发者模式」 Edge 地址栏输入 edge://extensions；Chrome 输入 chrome://extensions。打开页面右上角（或左下角）的「开发者模式」开关。
点「加载解压缩的扩展」，选刚才那个文件夹 选中解压出来的文件夹（里面能看到 manifest.json 的那一层），确定。列表里出现「岗位雷达 JobRadar」就成功了。
把图标固定到工具栏（建议） 点浏览器右上角的拼图图标 🧩，找到「岗位雷达」，点旁边的图钉固定。以后点它就能打开简历匹配、筛选设置、导出结果。
装完没反应？① 确认你是在 www.zhipin.com 的搜索结果页（地址里带 /web/geek/job），首页和职位详情页右侧不会出现面板；② 装完后刷新一次 BOSS 页面；③ 扩展管理页里确认它是「已启用」状态。

03三分钟上手（第一次建议只投 3 个）

第一次别放量。先投 3 个，确认话术真的发出去了、语气你自己能接受，再放开。

搜岗位在 BOSS 搜你要的方向关键词准一点
抓岗位往下滚两屏，面板自己收看「收录」涨
勾选勾上想投的，或点全选默认已勾前 15 个
调间隔新手 30–45 秒首用别低于 15 秒
自动投递点底部橙色按钮别关页面
在 BOSS 搜一个具体的岗位方向 例如「前端工程师」「AI 产品经理」「数据分析」。关键词越具体，抓到的岗位越准。搜完停在搜索结果页。
看右侧的「岗位雷达」面板，展开它 默认是一条很小的迷你条（显示「岗位雷达 · N」），点一下展开。然后往下滚两屏，让 BOSS 把职位列表加载出来——面板就是靠这些卡片和接口响应来收录岗位的。
点一面板里的「简历匹配」把你的简历放进去（可选但强烈建议） 上传 .docx/.txt 或直接粘贴简历文字 → 点「解析简历」。它会找出前 10 个最匹配的岗位，并且给每个岗位生成一条不一样的话术。详见 06。如果你就想用同一句话术投所有岗位，跳过这步，去「筛选设置」里填自定义打招呼语即可。
回到面板，确认勾选和间隔 看到「已选」的数字和底部「自动投递 N 个」是同一个数字就对了。把「间隔」调到 30–45 秒（第一次用别贪快）。
点「自动投递 N 个」，然后不要关这个页面 面板会显示「正在投递 3/15」和进度条。它会自动打开每个岗位详情页、点「立即沟通」、补发话术、关掉、等间隔、下一个。每投一个 BOSS 页面会闪一下，是正常的。想停随时点「停止」。
投完去哪看结果？① 面板顶部「已投」数字会涨；②「筛选设置」页最下面有「投递日志」，能看到每一条的标题、时间和结果；③导出按钮可以导出 CSV（含岗位链接），方便你自己记表。

编号是什么怎么看
① 顶部统计 收录 / 已选 / 可投 / 已投 / 今日 收录=当前搜索词下抓到几个（池子里可能还有别的词搜来的，不算）；已选=你现在勾了几个；可投=有详情页链接且还没投过的；已投=累计投过多少家；今日=今天投了几个 / 上限。
② 抓取计数 抓取通道的计数 两个数字都大于 0，说明抓取正常。点它一下会复制诊断信息（页面结构片段 + 薪资原文，不含账号信息），抓不到岗位时把这段发给开发者最快。
③ 搜索框 换关键词 改完点「搜索」，会直接跳到 BOSS 的搜索结果页。在这里换词，简历匹配页会跟着换一批岗位。
④ 简历匹配 核心功能入口 放进简历，按匹配度排序并给每个岗位生成专属话术。副标题写「已同步 10 个」就是已经用上了。
⑤ 节奏 节奏 间隔=两次投递之间等多久；默认勾=自动帮你勾分数最高的前几个（不影响你手动勾的数量，勾多少就投多少）。
⑥ 筛选 只看通过 / 重新打分 / 筛选设置 只看通过=隐藏被排除的岗位；重新打分=改了设置后用；筛选设置=打开详细偏好页（薪资、通勤、加分踩雷词等）。
⑦ 分数 0–100 的匹配分 绿 ≥80、蓝 65–79、黄 50–64、红 <50。分数下面的小标签写着每一分怎么来的（+10 双休、-4 薪资低于期望），能一条条核对，不是黑箱。
⑧ 岗位名 点一下开详情页 点岗位名或整行 = 在新标签打开 BOSS 原页面，自己核对 JD。点勾选框不会误触打开。
⑨ 底部按钮 自动投递 N 个 / 导出 / 清空 N 永远等于「已选」。导出=CSV（含链接、分数、排除原因）；清空=清掉抓到的岗位（已投记录会保留）。

05勾选框到底是什么意思

这是被问得最多的一处，单独说清楚。

一句话：勾上 = 会投这个岗位，取消 = 不投。没有第三种状态。

  • 「已选」的数字、底部「自动投递 N 个」的 N、真正开跑时投的队列，永远是同一个数。你在列表里勾 34 个，按钮就是 34 个，投的就是 34 个，不会被偷偷截断。
  • 默认只勾分数最高的前 N 个（N 就是面板上「默认勾」那个档位，默认 15）。所以刚抓完 50 个岗位时你看到的是「已选 15」，不是 50——它不会替你决定投 50 家。
  • 想多投就点「全选」，或一个个勾；想少投就点「全不选」再挑。勾上/取消后数字立刻跟着变。
  • 灰掉的勾选框是不能投的：已经投过、没拿到详情页链接、或者被你的筛选条件排除了。鼠标停在上面会看到原因。
  • 勾选状态存在本地，刷新页面、关浏览器都不会丢。

列表为什么这么排

列表顺序不是单纯按分数，而是按「接下来会发生什么」：

分组含义会不会投
投 1 / 投 2 / 投 3…勾着的岗位，序号就是投递顺序（按分数从高到低）会
没勾选 · 不会投递分数够但你没勾的（含「词外」的）不会，勾上就会
已投过投过的岗位，勾选框禁用不会重复投
已排除命中踩雷词、薪资不达标、规模/区域被排除不会（关掉「只看通过」能看到理由）

看到「词外」标签是什么意思？这个岗位的标题和标签里没有你搜的词，通常是 BOSS 自己的推荐位、或者详情页的「相似职位」混进来的。它们默认不勾、也不会被「全选」勾上——真想投，自己单独勾。

06用简历找最匹配的岗位

这一步是它跟「无脑海投」拉开差距的地方：先按你的简历排序，再给每个岗位写不一样的第一句。

打开「简历匹配」 点面板里那一行「简历匹配 · 打开 →」，或点浏览器工具栏的扩展图标 →「简历匹配 · 找最合适的岗位」。
放进简历 直接拖 .docx / .txt / .md 文件到虚线框，或点一下选文件；也可以把简历文字整段粘贴到下面的输入框。看不到具体格式要求没关系，正文能读出字就行（扫描件图片读不出来）。
点「解析简历」 右边会显示：识别到几年经验、期望薪资、所在城市、技能标签、几条可用原句（这些原句会被拼进话术里，所以第 3 行提示「识别到 N 条可用原句」很关键）。
看「最匹配的 N 个」 默认取前 10 个，可以改成 1–50。每个岗位一行：左边匹配分，中间岗位名 +「查看详情 ↗」（点开就是 BOSS 原 JD，方便你核对），下面是这个岗位专属的打招呼语，可以直接在里面改，右边显示字数（超过 180 字会标红，BOSS 聊天框显示不全）。
点「立即投递 N 个」 会写进投递计划、打开 BOSS 页面、自动开跑。也可以先点「只同步到面板」，回面板里自己再勾一遍。这页也能调发送间隔，并显示「预计 X 分钟投完 N 个」。
「岗位范围」那一行要对一下。如果你的岗位池里同时存着几个搜索词的岗位（比如先搜「测试」又搜「前端」），这里会显示「「前端」12」和「全部已抓 50」两个按钮。默认只按当前搜索词出结果——这是故意的，否则改完关键词看到的还是上一批岗位。

改了筛选设置里的岗位关键词，没生效？必须回 BOSS 重新搜一次（面板会抓到新一批岗位），再回来点「解析简历」。只在设置页改字、不去搜，池子里还是旧岗位。如果页面提示「设置里的岗位名称是 X，但池子里还没有这个词的岗位」，就点它给的「去搜 X ↗」。

07打招呼语：为什么对方会收到两条

这是产品层面绕不开的一件事，提前说明白，省得你以为坏了。

平台事实：你点「立即沟通」的那一刻，BOSS 会先自动发出它在站内保存的那句默认招呼语（通常是「您好，我对这个职位很感兴趣，可以聊聊吗？」）。这一步是 BOSS 自己做的，扩展拦不住、也改不了。扩展能做的是：紧接着在聊天框里补发第二条——你为这个岗位写的那句。

所以对方看到的是两条消息。这不算 bug。

把「两条」变成「一条半」的三个办法

  1. 去 BOSS 设置里把默认招呼语改到最短（比如就一个「您好」）。路径：BOSS 网页 → 右上角头像 → 隐私/打招呼设置里改「默认打招呼语」。这样第一条几乎不占字数，第二条才是重点。
  2. 话术开头不要重复自我介绍。因为第一条已经在问好了，第二条直接从「我看到岗位要求里提到 X」开始，读起来才连贯。
  3. 用「简历匹配」的专属话术，而不是一句通用模板。它会把岗位标题、JD 里的技术点、你简历里的原句拼进去——这是回复率的差别所在。

一条好话术长什么样

公式：JD 里一个具体技术点 + 一个可验证的结果 + 一个轻量的问题。

✗ 「你好，我对贵司岗位很感兴趣，期待回复。」——等于没说话。

✓ 「你好，看到岗位要向量检索这块，我上一个项目用 pgvector 做过 200 万条 embedding 的召回优化，QPS 从 30 提到 90。想了解下你们现在是自己搭还是用云服务？」

没有专属话术时，用的是「筛选设置」里那句自定义打招呼语兜底，所以那句也建议填上。

08参数怎么调（这是生死线）

调太快、投太多，是这套东西唯一会真正伤到你的地方。

参数建议值说明
岗位之间的间隔新手 30–45 秒
日常 12–20 秒		面板里点 − + 就能改，简历页也能改。低于 8 秒被限流的概率明显上升，别为了快把账号搭进去。
默认勾选数量首次 3，日常 10–20只决定「自动帮你勾几个」。勾上的一律会投，手动勾多少就投多少。
每日最多投递≤ 40BOSS 对单日沟通数有隐性阈值。到上限会自动停，并在面板提示。
自定义打招呼语必填留空就是用 BOSS 的默认模板语，那投了跟没投差不多。用了简历匹配的话，这句只在没有专属话术时兜底。

  • 面板只出现在搜索结果页（地址里有 /web/geek/job）。BOSS 首页、职位详情页、聊天页都不显示。
  • 装完要刷新一次页面，或者关掉标签页重开。
  • 面板默认是收起的迷你条，在页面右侧，写着「岗位雷达 · N」，点它才展开。如果连迷你条都没有，去扩展管理页确认扩展是「已启用」。
  • 如果你改过浏览器缩放或用了深色主题插件，面板可能被挤到屏幕外——按 Ctrl+0 恢复 100% 缩放试试。
收录一直是 0，抓不到岗位
  • 在搜索页往下滚两屏。BOSS 的岗位是滚动加载的，不滚它不会请求数据。
  • 按一次 F5 刷新。刷新时扩展会重新挂载，是最有效的一招。
  • 看面板上「接口 1 · DOM 3」这两个数字：都大于 0 说明通道是通的，只是这批没数据；一直是 0 才说明真没抓到。
  • 还是 0 的话，点一下这两个数字，诊断信息会复制到剪贴板，发给开发者能直接定位（里面不含你的账号信息）。
按钮显示「自动投递 0 个」，点了没反应

先看顶部「可投」那个数：

  • 可投 = 0，收录 > 0：岗位没拿到详情页链接，或者都投过了。做法：回搜索页按 F5 重抓一次。
  • 收录 = 0：当前搜索词下没岗位（池子里那批是别的词搜的，被故意排除了）。去 BOSS 搜你设置里那个词。
  • 可投 > 0 但已选 = 0：你没勾任何岗位。点「全选」，或手动勾几个。
  • 今日 40/40：到每日上限了。去「筛选设置」调高上限，或明天再投。
岗位投出去了，但对方只收到一句「您好，我对这个职位很感兴趣」

那是 BOSS 的站内默认招呼语，不是你写的那句。说明第二条没发出去，常见三种原因：

  • 话术为空：既没做「简历匹配」，也没在「筛选设置」里填自定义打招呼语。去填一句。
  • 页面没加载完就点了：间隔太短（<8 秒）时容易发生。把间隔调到 15 秒以上重投一次。
  • 被风控限流：连续快速投递后，BOSS 会限制发消息。停一天，间隔拉长到 30 秒以上。

另外请记住：第一条默认语永远会发，扩展只能补第二条（详见 07）。

简历页点「解析简历」，出来的还是上一次那批岗位

原因是简历页是常驻标签页，它不知道你在 BOSS 那边换了词。

  • 正确姿势：在 BOSS 里搜新词 → 滚动抓到岗位 → 回简历页点「解析简历」（现在它会自动重读一次数据，不用刷新页面）。
  • 看「岗位范围」那一行：如果显示的是旧的词，点一下写着新词的那个按钮切换。
  • 只在「筛选设置」里改关键词、不去 BOSS 搜，池子里不会凭空多出新岗位——页面会黄字提醒你「去搜 X」。
列表里出现跟我搜的岗位完全无关的东西（标着「词外」）

那些是 BOSS 的推荐位、或者从详情页「相似职位」抓到的，标题里根本没有你搜的词。它们被标成 词外，默认不勾、不会被「全选」勾上，也不会被投递。

如果你觉得某一批整体跑偏了，通常是搜索词太宽（比如只搜「工程师」）。换个具体点的词，然后按 F5 重抓。

分数看不懂，为什么这个岗位 40 分排在上面？

分数下面是它的「账单」，每个标签就是一条加减分记录，例如 +10 双休、+9 通勤命中、-4 薪资低于期望、-13 踩雷 单休。全部加起来就是那个分数。

觉得某条不合理，就去「筛选设置」改对应的词/值，回来点「重新打分」即可，不用重新抓岗位。

能同时开两个 BOSS 标签页吗？投递的时候我还能用电脑吗？
  • 可以同时开，但投递期间别在那几个标签页上点来点去——扩展需要它们保持可见，切到后台可能被浏览器节流。
  • 投递时它会在同一个标签页里轮转（不会给你开一堆新窗口），页面会逐个闪一下，所以那段时间最好别用这个标签页做别的事。
  • 想停下随时点面板上的「停止」；把小窗/标签页关掉也会停，不会失控继续投。
刷新、重启电脑之后，我的勾选和已投记录还在吗？

都在。勾选、已投记录、话术、筛选设置全部存在本机浏览器里。同一个岗位投过之后会被记住，不会重复投——除非你去「筛选设置」里点「重置已投记录」。

换电脑 / 重装浏览器，数据会跟过去吗？

不会。数据只在这台电脑的浏览器里，不跟账号绑定。换机器前先在「筛选设置」里导出 CSV 备份（岗位表和投递日志各一份），至少知道自己投过哪些公司。

支持手机 / 支持 Safari / 支持 Firefox 吗？

都不支持。它是桌面浏览器扩展，需要 Chromium 内核（Edge、Chrome、以及基于它们的浏览器），版本 111 以上。手机上 BOSS 的投递体验也没法自动化。

会把我的简历、账号信息传到你们服务器吗？

不会。扩展只申请了 storage（本地存数据）、tabs（切换标签页）、downloads（导出 CSV）三个权限，域名权限只有 zhipin.com 和 restapi.amap.com（只有你自己填了高德 Key 才会请求）。简历原文、岗位、话术都只在你本机。

10风险与边界（请认真看这一段）

这段不是免责声明，是使用建议。它决定了你能不能用得久。

自动点击属于自动化行为，违反 BOSS 直聘的用户协议，存在被「打招呼受限」甚至封号的真实风险。这跟工具做得好不好没关系——平台一直在检测。

能降低风险的做法：间隔 ≥ 12 秒（新手 30 秒以上）、每日 ≤ 40、只投真正想去的岗位、别 24 小时挂着跑、新账号第一天先投 3 个看看。以上是保守基线；后续实测 5 秒间隔亦未触发风控，但请以自己账号的实际反馈为准（见 08 节的实测补充）。如果收到「操作频繁」提示或弹出真人验证，立刻停止，调大间隔后再说。

使用心态建议

  • 它是漏斗的上半段，不是全部。它负责把 50 个岗位筛成 15 个「值得聊」的，剩下聊得好不好，还是看你的话术和简历。
  • 每天投 20–30 个高质量的，比一天投 200 个模板消息回复率高得多。BOSS 的 HR 一眼就能看出群发。
  • 投之前扫一眼分数下面的标签。如果看到「-4 薪资低于期望」「-13 踩雷 单休」，那就是你自己设的筛子在工作，别硬投。
  • 别用它投完全不匹配的岗位。除了浪费每日额度，还会把你的账号画像搞差（HR 侧会看到你的投递记录）。
