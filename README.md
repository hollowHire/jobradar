# 岗位雷达 JobRadar

在 BOSS 直聘搜索页批量抓取岗位，按薪资、通勤、双休、关键词等偏好打分排序，勾选后按设定间隔自动投递打招呼语。所有数据只存在本机浏览器，不上传服务器。

- **当前版本**：v0.8.6（快照）
- **运行环境**：Chrome / Edge 111+，Manifest V3 扩展
- **完整文档**：[岗位雷达使用说明书](docs/岗位雷达使用说明书.html)（下载后用浏览器打开即可）

> ⚠️ 自动点击属于自动化行为，可能违反 BOSS 直聘用户协议，存在被限制打招呼甚至封号的风险。使用前请先阅读说明书第 10 节「风险与边界」。

## 安装

两种方式任选其一：

**A. 直接加载仓库源码（推荐）**

1. 克隆本仓库（或下载 ZIP 并解压到一个固定目录）；
2. 地址栏打开 `edge://extensions` / `chrome://extensions`，开启「开发者模式」；
3. 点「加载解压缩的扩展」，选择仓库根目录（能看到 `manifest.json` 的那一层）。

**B. 下载压缩包**

在仓库页面点 **Code → Download ZIP**，解压到固定文件夹后按同样方式加载。GitHub 自动生成的包里多了 README 和 docs，不影响扩展加载。装好后不要移动或删除该文件夹，否则扩展会失效。

装完刷新一次 BOSS **搜索结果页**（地址含 `/web/geek/job`），页面右侧会出现「岗位雷达」迷你条，点它展开面板。

## 兼容性

按 Manifest V3 规范整理，适用于 **Chrome / Edge 111 及以上**（`world: "MAIN"` 的注入脚本需要 111+，`minimum_chrome_version` 已声明）。已静态核对：

- `manifest.json` 为合法 MV3，且能被本机 Chrome 157 的打包器（`--pack-extension`）正常解析并产出 `.crx`；
- 8 个 JS 文件全部通过语法检查，HTML 中引用的脚本与资源齐全；
- 扩展页只引用外部 `.js`，无内联脚本、内联事件或 `eval`，符合 MV3 的 CSP；
- service worker（`background.js`）不依赖 DOM / `window`，MAIN world 的 `inject.js` 不调用任何 `chrome.*` API；
- 用到的 `chrome.storage` / `chrome.tabs` / `chrome.windows` / `chrome.action` / `chrome.runtime` 都在各自上下文中可用，且没有使用未声明权限的 API。

> 未覆盖：登录态下 BOSS 直聘页面的端到端联调（站点 DOM 改版会影响抓取，与浏览器兼容性无关）；Chrome 网上应用店上架审核是另一回事。安装时 Chrome 会提示「读取和更改您在 zhipin.com 上的数据」，属正常权限声明。

## 投递节奏与风控

- **实测结论**：每 **5 秒**投递 1 个岗位，未触发风控。
- **出现真人验证时**：立刻点「停止」暂停投递，把**投递间隔调大**、放慢节奏，等一段时间再继续，不要连续硬闯验证。
- 说明书给的是更保守的建议（首次 30–45 秒、日常 12–20 秒、每日 ≤ 40 个）。5 秒是实测经验值，不同账号、不同时段的风控策略会有差异；第一次使用仍建议从较慢的节奏起步，观察账号状态后再调整。

> 说明书写作时间早于本次实测，参数章节保留了原来的保守建议。两处不一致时，以你账号的实际反馈为准。

## 目录结构

```
.
├── manifest.json           # 扩展配置（MV3）
├── background.js           # 后台调度、投递队列
├── inject.js               # 页面注入脚本
├── matcher.js              # 打分与匹配规则
├── content.js              # 侧边面板、抓取、投递执行
├── popup.* / options.*     # 工具栏弹窗、筛选设置页
├── resume.* / resume-io.js # 简历解析与专属话术
└── docs/                   # 使用说明书（HTML）
```

## 隐私与权限

扩展只申请 `storage`、`tabs`、`downloads` 三个权限，域名权限仅限 `zhipin.com` 与 `restapi.amap.com`（后者只有在你自行填入高德 Key 后才会请求，用于计算通勤距离）。源码中不包含任何密钥。

简历原文、岗位数据、话术、勾选状态和投递记录都留在本机浏览器，不跟账号绑定。换电脑或重装浏览器前，先在「筛选设置」里导出 CSV 备份。
